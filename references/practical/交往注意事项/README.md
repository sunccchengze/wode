## 先读这三条，再用这个目录

**1. 这是为一个人写的，不是通用建议。**
16 份全部以「读者 = 孙承泽 = INTJ（Ni-Te-Fi-Se），中阶」为前提。每份的「你最容易踩的雷」讲的是**他的**盲区（共享 Se 劣势、Fe 诡匠、双 J 竞争），「你的优势怎么用」讲的是**他的**优势。发给别人之前必须按对方的类型与功能栈重写，否则就是把一个人的病历当通用处方。

**2. 里面的百分比是众包投票，不是测量值。**
「化学值 93%」「70/100 good match」「Playmate／Alter Ego」全部来自 personality-database 口径的类型文学。数字**保留着**（主人 2026-09-06 明确「我其实还挺想看一下数字的」），但它们是 D 级来源：能说明「和这个类型聊天大概什么手感」，不能说明「该不该在一起」。

**3. 同屏必须给的反证。**
MBTI 类型配对对关系长久的预测力实证上极弱：Marioles et al. (1996) 的 426 对夫妻 7 年纵向对「异性相吸」只有极小支持；Kim & Lee (2010, *J Korean Acad Nurs* 40(3):336-, doi:10.4040/jkan.2010.40.3.336) 的 62 对临床夫妻里，**MBTI 类型相似性与婚姻满意度、正性情感、冲突调节均无显著差异**。真预测因子按强度是：低神经质、高宜人性、依恋安全、共享价值、沟通质量、性兼容。
